# Documentation

`mobile-network-sim` simulates mobile radio links and a simplified, step-based UE RRC state machine. The radio model can run on its own or feed RRC on the same time grid.

- [Usage](usage.md): installation, CLI output, Python runners, and saved measurements.
- [Configuration](configuration.md): YAML structure and time-grid rules.
- [Model scope](model-scope.md): implemented behavior and model boundaries.
- [RRC model](rrc.md): handover, radio-link monitoring, and model limits.
- [Python API](api.md): supported imports and main methods.

Runnable configurations are in [`examples/`](../examples/).
